# pydocformatter comment formatting (PCF)

## What it does
The PCF category contains rules that detect Python comments requiring line wrapping or related formatting changes.

## Why is this useful?
Consistently formatted comments remain readable within configured line-length limits without changing the surrounding code.

## Rules
Rules in this category distinguish standalone comments from trailing comments so each form can be formatted appropriately.

## Related tooling
Individual rule documentation describes relevant Ruff compatibility and differences.
