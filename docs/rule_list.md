## Ruff Rules

The pydocformatter tool aims to tightly complement Ruff in the formatting and linting of Python docstrings and comments.

The following table is up to date for Ruff v0.15.12 as per the published [Rules](https://docs.astral.sh/ruff/rules), in particular the [pydocstyle (D)](https://docs.astral.sh/ruff/rules/#pydocstyle-d) and [pydoclint (DOC)](https://docs.astral.sh/ruff/rules/#pydoclint-doc) rules.

Useful regex (PCRE2-flavor, tested in Kwrite) for converting entire collections of rows copied from [Rules](https://docs.astral.sh/ruff/rules) to Markdown format:
```
FROM: ([A-Z]+[0-9]{3})\t([a-z-]+)\t([^\n]+)\t(\nRule has been stable since v?([0-9.]+))?(\n..\nRule has been in preview since v?([0-9.]+))?(\n...\n(Auto)matic fix available)?
  TO: | \1 | [\2](https://docs.astral.sh/ruff/rules/\2/) | \3 | \9 | \7 | \5 |  |
```
