# Rule settings audit

This tracked audit records the settings each rule uses directly or through shared helpers. Update it whenever a rule implementation, helper, setting effect, or rule `## Options` section changes. The audit is intentionally based on implementation paths, not on existing rule documentation.

Every rule is also affected by `global-selection` and, where fixable, `global-fixability`. Eligible behavior settings may additionally be overridden through `per-file-settings` after selection. These mechanisms are intentionally excluded from rule `## Options` sections. Rule `## Options` sections also exclude `line-ending`, `docstring-convention`, parser-only `docstring-parse-*` settings, and settings read only by shared category preparation.

## Per-rule settings table

For each new or changed rule, audit both the rule module and any helper or category preparation code it calls. In the `Rule-specific selection effects` column, *disabled* means the rule is always removed for the listed resolved values, while *ignored* means only broad selections are removed and an exact rule-code or rule-name selection can restore the rule. The column must reproduce all `RuleMetadata.setting_effects` entries. The `Options settings to document` column must match the setting keys listed in that rule's `## Options` bullets, or be `None` when the section is `None.`.
