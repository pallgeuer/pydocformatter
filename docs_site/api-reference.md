# API reference

pydocformatter's primary supported public interface is the `pydocfmt` command-line interface.

Generated Python API reference pages are intentionally deferred while Zensical's native [API reference support](https://zensical.org/about/roadmap/#api-documentation) matures. The project will add API reference pages when they can be generated natively by Zensical.

Developers can inspect the source and type annotations in the [GitHub repository](https://github.com/pallgeuer/pydocformatter) for now.
